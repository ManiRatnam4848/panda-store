# Panda Store

A modern e-commerce storefront for merchandise and products. Built with React, TypeScript, Tailwind CSS, Three.js, and Motion.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- Motion
- Lucide React

## Setup

```bash
# install dependencies
npm install

# start local dev server
npm run dev

# build for production
npm run build

# preview production build
npm run preview
```
